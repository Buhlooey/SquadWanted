# SquadSpotter!

Find the wanted member of the elusive Squad association in the crowd of clones(? Holograms? Honestly we don't know either). We don't know what they're up to, but it certainly can't be good. Thank you for your participation in the SquadSpotter Operation!

SquadSpotter is a silly Godot game featuring a bunch of friends.
